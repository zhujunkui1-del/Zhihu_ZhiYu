# 知遇 ZhiYu · 产品计划书（简版）

> 知乎黑客松「灵魂匹配局：社区连接与兴趣社交」赛道

## 一句话

**让 Agent 先替你认识一个人。**

---

## 问题

从"看到一个人"到"认识一个人"，中间的成本极高：简介写不下，动态看不出，一次试探性对话又太贵。于是大量高价值的连接，**还没开始就结束了**。

这不是界面问题，是**信息量问题**——判断"我和这个人合不合得来"，需要的信息远超一个人能主动表达的量。

## 解法

把

```
人 → 人
```

改成

```
人 → Agent → Agent → 人
```

让一个真正了解你的 Agent，先去和对方的 Agent 聊一次。聊完你觉得值得，再由你们本人认识。

---

## 三个判断

**① 目标不是"最像"，而是"最值得认识"**

社区里最可惜的错过，往往是"观点不同但能相互启发"的两个人。

所以我们不按单一相似度排序，而是五维加权——其中**「互补程度」是反向的**：越不像，这一维越高。

> 真正适合认识的人，不一定是最像你的人。

**② Agent 对话不能是自由聊天**

自由聊天无法比较、无法解释、无法复现。所以每次匹配只跑**固定轮次的定向提问**，双方 Agent 各自作答，最后交给 Judge Agent 评分并给出理由。

**③ 关系需要"看得见的地图"**

"相似度 87%"人脑理解不了。所以做了**相遇雷达**：以你为中心，每个候选人的头像落在轨道上，**离你越近就越同频**，一次看到几十个人的相对位置。

---

## 用户会经历什么

1. **把"我"交给 Agent** — 六源任选其一：知乎（表达的我）、微信/QQ（真实的我）、飞书/钉钉（工作中的我）、SBTI（认识的我）
2. **生成我的 Agent** — 不是贴标签，而是理解你为什么喜欢、怎么思考、和谁聊得来
3. **两级匹配** — 先规则算分（秒级、零成本），再让 Agent 真实对话（只对少数候选）
4. **后台进行** — 点「让我的 Agent 先聊聊」后**不跳页不阻塞**，侧栏小圆点提示进度，聊完通知你
5. **拿到报告** — 五维评分 + 综合分 + **为什么推荐你们认识**

## 技术

**单体 Next.js（App Router）+ Vercel + PostgreSQL**

7 个页面（6 个 Server Component 首屏带数据）· 20 个 API · 14 个数据模型 · 92 个源码文件。

**最关键的一个架构判断：Agent 不常驻。**

不能让上亿 Agent 互相寻找（O(N²)）。正确做法是**检索而非全连接**：

```
海量 Persona Index → 向量召回 1000 → 规则精排 100 → 推荐 10 → Agent 对话 1~3
```

**LLM 只在最后一公里调用。**

**知乎数据接入**：已用真实凭证跑通用户数据 API 五个接口（创作/关注/收藏夹/收藏夹内容/近期收藏），把「知乎 · 公共表达」这一源从假注入变成**真同步**。

**已验证**：373 项自动化断言全部通过。

## 对知乎社区的价值

**① 知乎的数据形态天然适配"深层匹配"**

| 平台 | 数据性质 | 能推断 |
|---|---|---|
| 短视频/图片社区 | 消费行为 | 喜欢什么 |
| 生活社交 | 关系链 | 和谁熟 |
| **知乎** | **公开长文本表达** | **怎么想、在意什么、专业在哪** |

判断两人是否值得认识，最需要的就是最后这一类信息——**而这正是知乎独有的**。

**② 五个具体场景**

- **把单向关注变成可认识的关系** — 长期读某人的回答却没有契机开口，现在有了理由
- **找到同领域的陌生人** — 内容平台的推荐优化"内容触达"，不是"人的连接"
- **让观点碰撞成为推荐理由** — 「互补程度」专门给"异见但能相互启发"的人加分，主动对抗信息茧房
- **提升长文创作的连接回报** — 写得多、写得深，Agent 越能代表你，越能匹配到合适的人
- **激活沉默的深度用户** — 用「人格完整度」而非"发帖量"衡量一个人

**③ 是增量，不是分流**

入口在知乎数据上（用得越深越依赖知乎）· 匹配起点是"你们都在讨论什么"而不是"你们在同一城市" · 人格资产来自创作，给"多写、写深"新的正反馈 · 不做聊天工具替代品，只负责判断值不值得认识。

**④ 边界**

只读 OAuth 授权范围内的公开数据，不触碰私信，不做导出。设置页三个隐私开关**服务端真实执行**（关闭「展示相似度」就真的不进候选池）。`access_token` 加密落库，浏览器永远拿不到。
