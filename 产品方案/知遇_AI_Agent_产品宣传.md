# 🧠 知遇｜在你认识一个人之前，让 Agent 先认识 TA

大家好，我们正在参加知乎 Hackathon「灵魂匹配局：社区连接与兴趣社交」赛道。

我们正在做一个有点“赛博相亲”的项目：

## **知遇 —— 让 Agent 先替你认识一个人。**

你有没有遇到过这种情况：

> 加了一个新好友，聊了半天才发现完全聊不到一起。
> 或者看到一个很感兴趣的人，却不知道 TA 到底是不是“同频的人”。

我们突然想到：

**如果每个人都有一个了解自己的 Agent，会不会可以先让 Agent 替我们认识彼此？**

于是我们想做这样一套系统：

### 🧩 第一步：把“我”交给 Agent

我们支持多源人格输入（全部经本人授权，通过官方渠道或本机合规工具获取）：

**① 生活聊天（微信 / QQ）—— 真实的我**

从授权提供的聊天记录中，分析一个人的表达习惯、沟通方式、兴趣和熟人社交特征。

**② 职场资料（飞书 / 钉钉）—— 工作中的我**

从授权的工作沟通与文档中，理解一个人的思维方式、知识结构和职业偏好。

**③ 知乎数据 —— 表达的我**

从本人授权同步的知乎内容中，了解一个人的兴趣领域、知识结构和观点表达。

**④ SBTI 人格测试 —— 认识的我**

通过人格测试，让用户主动告诉 Agent：“我认为自己是怎样的人。”

几类来源可以任选其一，也可以全部完成。

数据越丰富，Agent 对你的理解就越完整。

---

### 🤖 第二步：生成“我的 Agent”

我们会把这些信息融合成一个属于你的 Persona，再让它成为一个真正能够代表你的 Agent。

它不是简单地给你贴一个：

> “INTJ / 内向 / 喜欢 AI”

这样的标签。

我们更希望它知道：

> 你为什么喜欢这些东西？
> 你怎么思考问题？
> 你习惯怎么和别人交流？
> 什么样的人会让你觉得“聊得来”？
> 什么样的观点会让你忍不住想反驳？

---

### 💘 第三步：让 Agent 帮你找人

当两个 Agent 相遇，我们不只比较“你们有多像”。

我们会从多个维度进行匹配：

**兴趣同频**
**思维同频**
**价值观适配**
**沟通方式适配**
**互补程度**

因为我们认为：

> **真正适合认识的人，不一定是最像你的人。**

有时候，一个和你完全不同、却能和你产生思想碰撞的人，反而更值得认识。

---

### 🌌 第三步之前：先看清"谁离我更近"

知遇不会只给你一列卡片。在「发现」页，你可以把结果切成**相遇雷达**：

一个以**你**为中心的星图。每一个候选人的头像落在轨道上，
**离你越近，说明你们越同频**；点一下头像，就能打开 TA 的人格卡。

拖动可以平移，滚轮可以缩放，也可以一键"全览"看整片关系分布。
一次就能看到几十个人的位置关系，而不是一张一张翻卡片。

> 我们想让"谁和我相似"这件事，从一串数字变成一张**看得见的地图**。

---

### 🗣️ 更有意思的是：让两个 Agent 先聊聊

如果你对某个人感兴趣，可以主动点击：

> **「让我的 Agent 先聊聊」**

**你不需要守在这一页等。** 两个 Agent 会立刻转到后台开始对话，
你可以继续浏览其他的人——侧栏会出现一个小圆点提示"后台正在聊"，
聊出结果时会通知你。

两个 Agent 会围绕一些能够暴露兴趣、价值观和思维方式的话题进行交流。

比如：

> “如果突然获得一周完全自由的时间，你会怎么安排？”

> “如果你可以重新选择一次自己的专业，你会怎么选？”

> “一个和你观点完全不同的人，你更愿意说服 TA，还是理解 TA？”

聊完以后，系统再给出一份：

### 💫 Agent 匹配报告

例如：

> 兴趣同频：87%
> 思维共振：92%
> 沟通适配：89%
> 互补程度：94%
> 综合推荐：91%

并告诉你：

**“为什么推荐你认识 TA？”**

---

## 🌌 我们真正想做的，不是一个赛博交友平台

而是一个新的社交方式：

**人 → 人**

变成：

**人 → Agent → Agent → 人**

以前认识一个人，需要自己一点一点试错。

以后也许可以：

> **先让你的 Agent 认识 TA 的 Agent。**

如果两个 Agent 聊完都觉得：

> “这个人，好像挺有意思。”

那么——

### **再由你们真正认识彼此。**

这就是我们正在做的 **「知遇」**。

我们希望最终回答一个问题：

> **如果 AI 已经足够了解“我”，它能不能帮我遇见一个真正值得认识的人？**
