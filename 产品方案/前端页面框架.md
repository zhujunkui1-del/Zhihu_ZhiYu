## Profile 设置页功能说明

设置页以 ZhiYu18 的 `zhiyu-settings.html` 为基准，共四区：

1. **01 身份与数据源**：展示知乎账号授权状态（已授权/未授权），以及微信 / QQ / 飞书 / 钉钉 / SBTI 的注入状态与入口（去接入 / 去完成测试）。
2. **02 Agent 沟通偏好**：三个开关，**默认全部开启**：

| 开关 | 默认 | 关闭后的行为 | 建议数据字段 |
|---|---|---|---|
| 允许他人派 Agent 与我对话 | 开 | 对方只能看到人格卡与相似度，不能发起 Agent 对话 | `user.communication_prefs.allow_agent_invite` |
| 允许在「快速匹配」中展示相似度 | 开 | 不进入快速匹配候选池，不被推荐给陌生人 | `persona.visibility.show_similarity` |
| 允许对方发送匹配报告给我 | 开 | 对方不能把匹配报告发送到我的账号（通知中心不出现） | `user.communication_prefs.allow_report_delivery` |

3. **03 AI 大模型接入**：见《AI模型接入设置方案.md》；API Key 采用服务端加密入库，延迟测试由服务端代理。
4. **04 账号与退出**：退出登录，返回登录页（含二次确认）。
