# 部署清单（Vercel + 自有域名 zhiyuapp.site）

> 适用状态：代码已推到 GitHub（`zhujunkui1-del/Zhihu_ZhiYu`），Vercel 已连接该仓库，
> 域名 `zhiyuapp.site` 已在腾讯云购买。
>
> **每一步都标了「在哪做」和「做完怎么确认」**，照着走即可。

---

## 第 0 步（必须先做）：修两个部署阻塞项

这两项**不修，第一次构建就会失败**。我已经在代码里改好并实测验证，你需要做的是**提交并推送**。

### 改动内容

| 文件 | 改了什么 | 为什么 |
|---|---|---|
| `zhiyu-web/package.json` | 加 `"postinstall": "prisma generate"` | 实测：没有它 Vercel 构建报 `Cannot find module '.prisma/client/default'` |
| `zhiyu-web/package.json` | 删掉 `@next/swc-win32-x64-msvc` | 那是 **Windows 专用**原生二进制（`os: ["win32"]`），Vercel 是 Linux，留着无用且有风险。`next` 自己会按平台装正确的那个 |
| `zhiyu-web/.env.example` | 重写，标注每个变量是否真被代码使用 | 清单要照着填，不能让人白填 |

### 你要执行

```bash
cd zhiyu-web
git add -A
git commit -m "fix(deploy): 加 postinstall 生成 Prisma Client；移除 Windows 专用 swc 依赖"
git push origin master
```

> **我在本地已实测过这两处**：
> 移走 Prisma 生成物后直接 `npm run build` → 报 `Cannot find module '.prisma/client/default'`；
> 跑 `npm run postinstall` 后再 build → 成功。

**确认**：GitHub 上能看到这次提交。

## 第 1 步：在 Vercel 设置 Root Directory ⚠️ 关键

**在哪**：Vercel → 你的项目 → **Settings → Build and Deployment → Root Directory**

**填**：`zhiyu-web`

**为什么关键**：这个仓库根目录**没有 `package.json`**（应用在 `zhiyu-web/` 子目录）。
不设 Root Directory 的话，Vercel 在仓库根找不到 Next.js 项目。

**顺带确认**（同一页）：

| 设置 | 应该是 |
|---|---|
| Framework Preset | Next.js（自动识别） |
| Build Command | 默认（`next build`，不用改） |
| Output Directory | 默认（不用改） |
| Install Command | 默认（不用改，`postinstall` 会自动跑） |
| Node.js Version | 20.x 或更高 |

**确认**：保存后触发一次部署，构建日志里应出现 `Generated Prisma Client`。

## 第 2 步：填环境变量

**在哪**：Vercel → 项目 → **Settings → Environment Variables**

**逐个添加**（Environment 建议三个都勾：Production / Preview / Development）：

### 必需

| Name | Value | 说明 |
|---|---|---|
| `DATABASE_URL` | Neon **池化**连接串 | host 带 `-pooler` |
| `DIRECT_URL` | Neon **直连**连接串 | host **不带** `-pooler`；迁移命令用 |

> 这两个值在你本地的 `zhiyu-web/.env` 里已经有了，直接复制。
> 找不到的话：Neon 控制台 → 你的项目 → Connection Details → 分别选 **Pooled** 和 **Direct**。

### 生产必需

| Name | Value |
|---|---|
| `AUTH_ENC_KEY` | 32 字节 base64 |

**生成一个新的**（不要复用本地那个，生产与开发应分开）：

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

> 不配这一项，用户在设置页保存 API Key 时会直接报错——这是有意为之（宁可报错也不明文存）。

### 知乎接入（现在不填也能上线，登录页会自动回退「演示登录」）

| Name | Value | 现在能填吗 |
|---|---|---|
| `ZHIHU_APP_ID` | `530` | ✅ 能 |
| `ZHIHU_OAUTH_APP_KEY` | 你的 App Key | ✅ 能 |
| `ZHIHU_ACCESS_SECRET` | 你的 Access Secret | ✅ 能（读创作/关注/收藏已跑通） |
| `ZHIHU_OAUTH_REDIRECT_URI` | `https://zhiyuapp.site/api/auth/zhihu/callback` | ⚠️ 见第 4 步 |
| `ZHIHU_COMMUNITY_APP_SECRET` | 社区 API 的 app_secret | ✅ 能 |
| `ZHIHU_COMMUNITY_USER_TOKEN` | `0anq7q` | ✅ 能 |

**加完之后**：在 Environment Variables 页面右上角选 **Redeploy**，让新变量生效
（Vercel 不会自动用新变量重跑已有部署）。

**确认**：部署完成后访问 `https://zhiyuapp.site/api/health`，应返回 JSON。

## 第 3 步：初始化数据库（建表 + 灌演示数据）

**为什么需要**：Vercel 部署**不会自动跑数据库迁移**。表没建的话所有页面都会报错。

**在哪做**：**在你本地**（你的 `.env` 里 `DIRECT_URL` 已指向同一个 Neon 库）。

```bash
cd zhiyu-web

# ① 建表（部署环境用 migrate deploy，不会问你确认）
npx prisma migrate deploy

# ② 灌演示数据 —— 不灌的话页面是空的，评审看不到内容
node --env-file=.env scripts/seed-demo.mjs
node --env-file=.env scripts/seed-agent-match.mjs
```

**确认**：

```bash
npx prisma migrate status
# 应显示 "Database schema is up to date!"
```

> Neon 免费版有冷启动：**首次访问可能等几秒**。这是正常的，
> 建议评审前先自己访问一次「预热」。

## 第 4 步：绑定域名

你说 `www.zhiyuapp.site` 已可用、进度停在 **Add Custom Domain**。两件事要做好：

### 4a. 决定主域名并做跳转

Vercel 里两个域名都加上：

| 域名 | 建议角色 |
|---|---|
| `zhiyuapp.site`（裸域） | **主入口** |
| `www.zhiyuapp.site` | 301 跳到裸域 |

**在哪**：Vercel → Settings → Domains → 添加两个，然后在 `www` 那条选 **Redirect to** 裸域。

> 两种都行，但**必须统一**——因为下一步的知乎回调地址要跟它**逐字一致**。
> 建议统一用 **`https://zhiyuapp.site`**（不带 www，更短）。

### 4b. 检查腾讯云的 DNS 记录

**在哪**：腾讯云 → DNS 解析 → `zhiyuapp.site`

Vercel 会给你需要填的记录值（在 Add Domain 那一步会显示）：

| 主机记录 | 类型 | 记录值 |
|---|---|---|
| `@` | A | `76.76.21.21` |
| `www` | CNAME | `cname.vercel-dns.com` |

> 具体值**以 Vercel 页面上显示的为准**，别照抄我这个。

**确认**：

```bash
# 本地执行
nslookup zhiyuapp.site
curl -I https://zhiyuapp.site
```
应为 200 或 308，且 HTTPS 证书有效（Vercel 自动签发，首次要等 1~5 分钟）。

### ⚠️ 不要做的事

- **不要把 `*.vercel.app` 作为对外入口。** 实测（中国大陆网络）Vercel 的
  `*.vercel.app` 子域被 DNS 污染 + TCP 443 超时，而自定义域名可达 119–500 ms。
  赛事评委打不开会扣分。
- **不要在 Vercel 前面套 Cloudflare 代理**（Vercel 有明确反代政策）。

## 第 5 步：登记知乎 OAuth 回调

**在哪**：知乎开放平台（或黑客松赛事页面）→ 你的应用 → 回调地址

**填**（必须与第 4a 步选定的主域名**逐字一致**，含协议、域名、路径，结尾不能多斜杠）：

```
https://zhiyuapp.site/api/auth/zhihu/callback
```

**然后**回到 Vercel，把同一个值填进 `ZHIHU_OAUTH_REDIRECT_URI`，再 **Redeploy**。

**确认**：访问 `https://zhiyuapp.site/api/auth/session`，应看到 `"oauthConfigured": true`。

> 填完这一步，登录页的知乎按钮会**自动**从「演示登录」切换成「跳转知乎授权页」，
> **不需要改任何代码**。

## 第 6 步：上线验收

逐项走一遍，勾掉即可。

### 基础可达性

- [ ] `https://zhiyuapp.site` 能打开，且**中国大陆网络**也能打开（关掉代理试）
- [ ] HTTPS 证书有效，没有「不安全」警告
- [ ] 页面样式正常（字体、纸纹背景、logo 都在）——**验证静态资源自托管成功**

### 功能闭环

- [ ] 点「演示登录」能进入首页
- [ ] `/find` 发现页：卡片视图有 16 人
- [ ] `/find` 切到「相遇雷达」：头像排布成星图，能拖动、能缩放
- [ ] `/persona` 我的人格：五轴雷达有数据，人格倾向是**「深度思考型」**（不是「死者」）
- [ ] `/persona` 「注入数据」里点「连接知乎并同步」→ 能拉到你的创作/关注/收藏
- [ ] `/agent-match` 「认识中」有 3 组进行中的对话
- [ ] `/agent-match` 「匹配报告」→ 点「查看报告」→ 五维雷达 + 推荐理由 + 对话摘录
- [ ] `/notify` 通知页有消息
- [ ] `/settings` 三个开关能切换，刷新后**状态保持**（说明真的落库了）
- [ ] `/settings` 退出登录 → 回到登录页

### 安全

- [ ] 浏览器控制台执行 `document.cookie`，**看不到 `zhiyu_session`**（HttpOnly 生效）
- [ ] 换个浏览器/无痕窗口直接访问 `https://zhiyuapp.site/notify` → **应跳回登录页**，而不是显示别人数据
- [ ] 知乎 OAuth：点知乎登录 → 跳到知乎授权页 → 授权 → 回到站内且显示你的昵称头像

### 演示前最后一步（很重要）

- [ ] 跑一次 `node --env-file=.env scripts/seed-demo.mjs` 重置演示数据

> **为什么**：`RECON/verify-web-persona.mjs` 会跑完 30 题 SBTI 并**覆盖演示用户的人格
> 结果**（全选 A 得到「死者 / DEAD」）。我之前验证时就踩到过，首页标题变成了
> 「你的人格倾向是「死者」」。演示或截图前务必重置。

## 附：上线后遇到问题先看这里

| 现象 | 原因 | 处理 |
|---|---|---|
| 构建失败，报 `Cannot find module '.prisma/client/default'` | 第 0 步没推送 / Root Directory 不对 | 确认 `postinstall` 在 `zhiyu-web/package.json` 里 |
| 构建失败，报找不到 Next.js 项目 | Root Directory 没设 | 见第 1 步 |
| 页面 500，日志报表不存在 | 没跑迁移 | 见第 3 步 |
| 页面空白、无样式 | 静态资源没上传 | 确认 `zhiyu-web/public/assets/` 在 Git 里 |
| 首次访问很慢（几秒） | Neon 免费版冷启动 | 正常，提前预热 |
| 登录页知乎按钮点了没反应 | OAuth 凭证未配完整 | 看 `/api/auth/session` 的 `oauthConfigured` |
| 授权后跳回来报 `redirect_uri` 不匹配 | 登记值与 `ZHIHU_OAUTH_REDIRECT_URI` 不一致 | 两者必须**逐字一致** |
| 演示时人格显示成「死者」 | 跑过 SBTI 验证脚本 | 重跑 `seed-demo.mjs` |
| 中国大陆打不开 | 用了 `*.vercel.app` | 必须用自有域名，见第 4 步 |
