一次认识方式的升级

认识一个人，不再从试探与尬聊开始。

知遇把“人 → 人”的社交，升级为“人 → Agent → Agent → 人”：先让了解你的 Agent 去见了解 TA 的 Agent。

两个 Agent 聊完，都觉得 “这个人，好像挺有意思” 时，才轮到你们真正认识彼此。

三步，把“我”交给 Agent

每一步都在回答：它凭什么能代表我？

三种人格来源可以任选其一，也可以全部完成。数据越丰富，Agent 对你的理解就越完整。

01

把“我”交给 Agent

从不同侧面认识真实的你：聊出来的、表达出来的，以及你眼中的自己。

  • 微信聊天真实的我
  • 知乎数据表达的我
  • SBTI 测试认识的我
02

生成“我的 Agent”

把信息融成属于你的 Persona，不靠几个标签草率定义。

它知道你为什么喜欢、怎么思考，以及和什么样的人聊得来。
03

让 Agent 帮你找人

相遇时不只比较“你们有多像”，而是从五个维度判断彼此是否值得认识。

兴趣同频 思维共振 价值观契合 沟通适配 互补程度
