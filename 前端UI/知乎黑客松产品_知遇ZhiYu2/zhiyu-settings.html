01 · 身份与数据源

你以什么身份出现

人格来自你授权的数据源：六个来源各自独立、只标记“已注入 / 未注入”，融合成统一 Persona。状态口径与「我的人格」页保持一致。

知乎账号已授权（演示）

匹配与 Agent 只使用你授权的知乎公开内容作为人格输入之一，原始内容不用于其他用途。撤回授权后，知乎数据停止参与后续人格更新（已生成的人格不会被删除）。

微信数据源未注入

用微信聊天记录补充私域生活特征。处理走 WeFlow：先在本地完成聚合与人格蒸馏，只把需要的 Persona 结果上传，原始聊天记录不会离开你的设备。（演示：本页暂不提供接入，可去「我的人格」页体验流程。）

QQ 数据源未注入

用 QQ 群聊与常聊好友记录补充另一侧的私域生活特征。先在本地用 qq-chat-exporter 导出会话、完成说话人分离，只把需要的 Persona 结果上传。（演示：本页暂不提供接入，可去「我的人格」页体验流程。）

飞书工作数据未注入

通过飞书官方 API 读取你在工作沟通、文档与多维表格里的表达，作为职场画像输入。（演示：本页暂不提供接入，可去「我的人格」页体验授权流程。）

钉钉工作数据未注入

文档与多维表格走官方 API，聊天消息以本地导出上传，共同构成职场画像输入。（演示：本页暂不提供接入，可去「我的人格」页体验导入流程。）

SBTI 人格测试未注入

02 · Agent 沟通偏好

别人如何与你相遇

决定你在「发现」里的可见方式：对方能否派 Agent 与你进一步认识、能否在快速匹配里看到相似度，以及匹配结果如何通知你。

允许他人派 Agent 与我对话

对方看到你的人格卡后，可发起一轮 Agent 认识：他的 Agent 会与你的人格侧 Agent 做 5～8 轮对话并生成匹配报告。关闭后，对方只能看到人格卡与相似度，不能发起 Agent 对话。

已开启

允许在「快速匹配」中展示相似度

当你的人格数据可用时，你的 Persona 会进入快速匹配候选池，对方可以看到与你的人格相似度。关闭后，你不会被推荐给陌生人。

已开启

对方发来匹配报告时提醒我

当对方把「与你的人格匹配报告」发过来时，在通知中心提醒你；历史报告可随时回看。

03 · 数据与隐私

只带走「必要的人格」

知遇以人格数据为基础，因此隐私优先。以下是本项目固定遵守的原则，在演示原型中同样适用。

原始数据最小化

微信聊天记录等原始内容先在本地聚合与蒸馏，只有匹配所需的人格结果会上传；服务器不保存原始聊天数据。

真人与 AI 严格区分

每个 Persona 都带类型标注：真人使用 type = human，AI 演示人格使用 type = synthetic 并在界面中如实标明，不会冒充真人。

结论可解释

相似度与匹配报告都会给出来源证据和「为什么值得认识」的解释，而不只是一个分数。

我的人格

查看各来源的注入状态与融合后的人格卡；数据更新后，建议重新蒸馏你的 Agent。
